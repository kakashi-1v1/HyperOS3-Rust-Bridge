# HyperOS 4 runtime functions missing in runtime 1.5.0

Functions the HyperOS 4 launcher (8.01.02.9239) looks up at run time (`dlsym`) that exist in HyperOS 4's
`libhyper_os_*_public.so` (runtime 3.1.0) but not in runtime 1.5.0 or HyperOS 3's own libraries. The launcher
disables the matching feature when one is missing. Candidates for the shim (`shim/kashins.c`): the bridge already
provides `ComputilityLevel_*` and `get_rust_app_namespace`.
